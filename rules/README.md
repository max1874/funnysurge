# Surge rule sets · Surge 规则集

Plain-text rules without a policy column. Subscribe with `RULE-SET` and assign
the policy in your own Surge profile.

这里存放不含策略列的纯文本规则；通过 `RULE-SET` 引用，在自己的 Surge 配置中指定策略。
