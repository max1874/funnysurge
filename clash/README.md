# Clash / Mihomo rule providers · Clash / Mihomo 规则集

These `.txt` files contain YAML `payload` lists. Configure them as
`behavior: classical`, `format: yaml` rule providers, then reference the provider
name in `rules` with your chosen policy.

这些 `.txt` 文件包含 YAML `payload` 列表。使用 `behavior: classical`、`format: yaml`，再在 `rules` 中通过 provider 名称指定策略。

- [Rule catalog and raw links · 规则索引与原始链接](../docs/rules.md)
- [Setup guide](../docs/usage.md#clash--mihomo-rule-providers) · [中文配置指南](../docs/usage.zh-Hans.md#clash--mihomo-rule-provider)
- [Configuration snippet · 配置片段](../examples/clash-rule-providers.yaml)

Keep these filenames and paths stable: they are public subscription URLs.
文件名与路径属于公开订阅地址，整理时应保持稳定。
